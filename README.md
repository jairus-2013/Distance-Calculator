# DISTANCE BETWEEN TWO POINTS CALCULATOR

## DESCRIPTION
This program helps users calculate a distance between two points on a graph. It is fast and efficient even for beginners to use. This program contains a math library.

## HOW TO RUN
1. Open the file using a computer/any compatible device
2. Run the program
3. Enter the values asked
4. Check the answer displayed on the screen

## INPUT NEEDED
- var_x1
- var_y1
- var_x2
- var_y2

## SAMPLE OUTPUT
Enter your first x-value: 5
Enter your second x-value: 10
Enter your first y-value: 15
Enter your second y-value: 20
The distance between the two points is 7.0710678118654755
